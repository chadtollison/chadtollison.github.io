    How it works

    Your text is split into the same word pieces the model was trained on.

    02

    A DistilBERT model I fine-tuned labels every piece and gives a confidence score, running on your device with ONNX Runtime.

    Use it in your own code

    The model is free on Hugging Face. Three steps get it running in Python.

    1. Install Python and two libraries

      You need Python 3.9 or newer. Then run this in a terminal:

      pip install transformers torch

    2. Find personal data

      Save this as find_pii.py and run python find_pii.py. The first run downloads the model (about 260 MB) from Hugging Face. After that it works offline.

      from transformers import pipeline

pii = pipeline(
    "token-classification",
    model="ChadTollison/pii-distilbert-v2",
    aggregation_strategy="max",  # join word pieces into whole words
)

text = "Hi, I'm Sarah Johnson. Email sarah.j@example.com or call 415-555-0198."
for item in pii(text):
    print(item["entity_group"], text[item["start"]:item["end"]], round(item["score"], 2))

      It prints the type, the text and a confidence score for each item, something like this:

      PERSON Sarah Johnson 1.0
EMAIL sarah.j@example.com 1.0
PHONE 415-555-0198 0.99

    3. Redact it

      Add this to swap each item for a label, like this page does:

      def redact(text, min_score=0.5):
    for item in sorted(pii(text), key=lambda i: i["start"], reverse=True):
        if item["score"] >= min_score:
            text = text[:item["start"]] + f"[{item['entity_group']}]" + text[item["end"]:]
    return text

print(redact(text))
# Hi, I'm [PERSON]. Email [EMAIL] or call [PHONE].

    It finds PERSON, EMAIL, PHONE, SSN, CREDIT_CARD and IP_ADDRESS. For the full service with the Luhn and format checks and a ready-to-run API in Docker, see the PII-Detector repository.
