    Use it in your own code

    The model is free, and so is a small Python package that wraps it with the same checks this page uses. Two steps get it running.

    1. Install it

      You need Python 3.9 or newer. Then run this in a terminal:

      pip install chad-pii

    2. Redact some text

      Save this as redact_me.py and run python redact_me.py. The first run downloads the model (about 260 MB) from Hugging Face. After that it works offline, and nothing you redact is sent anywhere.

      from chad_pii import redact, tokenize, restore

text = "Hi, I'm Sarah Johnson. Email sarah.j@example.com or call 6626341142."

print(redact(text))                # labels
print(redact(text, mode="mask"))   # black bars
print(redact(text, mode="fake"))   # realistic fake values

safe, key = tokenize(text)         # reversible tokens
print(safe)
print(restore(safe, key) == text)

Use find(text) to get each item's type, position and confidence, or run chad-pii "some text" on the command line. The package checks card numbers with Luhn, IBANs with their bank checksum and SSNs by format, and catches 10-digit phone numbers with a real area code. See chad-pii on PyPI, or use the raw model with transformers from Hugging Face.
